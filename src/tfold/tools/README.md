# Tools

List of tool classes:

* `A3mParser`: parser for A3M files
* `ClashChecker`: steric clash checker for distance between non-bonded atoms
* `CntcAssessor`: assessor for long-range contact predictions
* `LddtAssessor`: assessor for per-residue lDDT scores
* `MetricRecorder`: recorder for evaluation metrics w/ Horovod support
* `MsaSampler`: sampler for multiple sequence alignment
* `PdbAssessor`: assessor for decoy PDB files
* `ProtStruct`: wrapper class for utility functions related to protein structures
